무료 체험인데, 별도 비용이 있나요?＋

프로그램의 7일 체험은 1인 1회, 카드 등록 없이 진행합니다. 자동으로 유료 전환되지 않습니다. AI 생성 기능은 외부 AI 서비스를 연결하는 본인 API 키가 필요하며, 해당 서비스 이용료는 기능·모델·사용량에 따라 별도로 발생합니다. 무료 도구 6종은 7일 체험과 별개입니다.

휴대폰이나 Mac에서도 실행할 수 있나요?＋

실행은 Windows PC에서 가능합니다. 휴대폰·Mac에서는 소개 영상과 기능을 확인하고, 설치 링크를 공유하거나 복사해 Windows PC에서 이어서 시작하세요. 영상·움짤 변환 등 일부 기능은 FFmpeg가 필요합니다.

원격 설치나 교육도 받을 수 있나요?＋

기본 카카오 상담과 설치·사용 가이드가 제공됩니다. 화면 공유·출장·4주 교육은 필요한 분만 별도로 선택하세요. 아래 금액은 VAT 포함 1회 결제이며 프로그램 이용료는 별도입니다.

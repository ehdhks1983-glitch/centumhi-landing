  • 사용자 중지 — 진행 중인 작업을 멈추고 설정을 다시 확인

어떤 자동화도 계정 제한 위험을 0으로 만들 수는 없습니다. 반드시 본인 계정·채널에서 각 플랫폼의 이용약관과 제품별 권장 한도를 지켜 사용해 주세요.

자주 묻는 질문

하나만 구독해도 되나요?

네. 8종 전부 단품으로 쓰실 수 있습니다. 지금 손이 제일 많이 가는 일 하나부터 시작하시고, 필요해지면 그때 패키지로 올리시면 됩니다. 블로그대리와 서이추대리처럼 같이 쓸 때 효과가 커지는 조합만 묶어서 할인합니다.

시작 전에 써볼 수 있나요?

네. 페이지의 ‘무료 7일 체험판 받기’ 버튼을 누르면 구글 드라이브에서 바로 받을 수 있습니다. 체험은 1인 1회·7일이며, 카드 등록 없이 시작하고 자동 유료전환 없이 만료됩니다. AI 기능을 사용하면 본인 명의 외부 API 사용료는 별도로 발생할 수 있습니다.

3개월·6개월·12개월도 자동결제되나요?

아니요. 3개월·6개월·12개월은 네이버페이·카카오페이·앱카드·카드를 지원하는 1회 결제 기간권입니다. 선택한 기간이 끝나면 자동으로 종료되며, 계속 이용하려면 직접 연장하면 됩니다.

1개월은 어떻게 결제되나요?

1개월은 래피드 정기구독 정책상 카드로만 결제하며, 해지 전까지 매월 자동결제됩니다. 기간권을 이용하려면 다음 월결제를 먼저 해지한 뒤 3·6·12개월 중 원하는 기간을 결제해 주세요.

해지와 환불 기준은 어떻게 되나요?

1개월 정기결제를 해지하면 다음 결제일부터 자동결제가 중단되고 이미 결제한 기간까지 이용할 수 있습니다. 3·6·12개월 기간권은 이용 시작 후 중도해지 시 결제금액에서 경과 일수의 일할 이용대금과 잔여기간 이용요금의 10%를 공제한 금액을 환불합니다. 교육은 시작 전 전액 환불하며, 원격·출장 1회 과정은 총 3시간, 4주 과정은 총 12시간을 기준으로 교육시간의 3분의 1 전에는 결제금액의 3분의 2, 2분의 1 전에는 2분의 1을 환불하고 절반 이상 진행된 뒤에는 환불하지 않습니다. 일정·출장 지역에 합의하지 못한 경우에는 전액 환불하며, 관련 법령이나 소비자분쟁해결기준이 더 유리하면 그 기준을 우선 적용합니다. 자세한 내용은 이용약관에서 확인해 주세요.

해지 후 언제까지 사용할 수 있나요?

이미 결제한 이용기간 끝날 때까지 그대로 쓰실 수 있습니다. 기간이 끝나면 프로그램 실행만 멈추고, 그동안 만든 글·영상·이미지는 내 컴퓨터에 그대로 남습니다.

표시된 금액이 최종 금액인가요?

네. 페이지에 적힌 프로그램 요금과 교육비는 VAT가 포함된 최종 결제 금액입니다. 교육비는 프로그램 구독료와 별도이며, AI 글·이미지·목소리 생성에 쓰는 외부 API 사용료와 추가 PC 라이선스도 별도입니다. 기본 프로그램 이용 조건은 1인·1PC입니다.

AI 사용료가 따로 드나요?

네. AI 기능은 본인 명의 API 키로 동작하며, 사용량과 선택한 제공사에 따라 별도 사용료가 발생할 수 있습니다. 곰대리가 별도 마진을 붙이지는 않습니다. 무료 제공 범위와 과금 기준은 AI 제공사에 따라 달라질 수 있습니다.

구독료에 원격설치가 포함되나요?

기본 제공 범위는 카카오톡 상담과 설치·사용 가이드이며, 고객이 직접 설치하는 방식입니다. 화면 공유 설치·사용법 과정, 출장 교육, 4주 과정은 프로그램 구독료와 별도인 유료 서비스입니다.

설치·교육은 어떤 방식으로 받을 수 있나요?

원격 3시간 과정(100,000원), 대면 출장 3시간 과정(200,000원), 1:1 원격 4주 과정(400,000원), 인천 교육장 4주 과정(500,000원) 중에서 선택할 수 있습니다. 교육비는 VAT 포함 1회 결제 금액입니다. 결제 후 2영업일 이내에 일정과 출장 가능 지역을 협의하며, 합의하지 못하면 교육 시작 전 결제금액을 전액 환불합니다.

프로그램 오류도 유료 교육을 결제해야 하나요?

아니요. 프로그램 자체 결함으로 확인된 문제는 설치 환경 설정이나 사용 교육을 위한 유료 서비스와 분리해서 처리합니다.

무료 도구 3종도 구독해야 하나요?

아니요. 키워드 관제탑, 이미지 누끼, 이미지공작소는 곰대리 구독 여부와 관계없이 무료로 제공하는 별도 도구입니다. 유료 패키지의 포함 제품 수(2·3·6·8종)에도 넣지 않습니다. 키워드 관제탑의 검색량·발행량 같은 일부 분석은 네이버 API 연결이 필요합니다.

앞으로 나오는 프로그램도 포함되나요?

구독하신 제품의 기능 개선과 호환성 업데이트는 이용기간 내내 제공됩니다. 다만 완전히 새로 나오는 유료 독립 제품은 별도 상품이거나 구독자 전용 조건으로 안내드립니다. 무료로 배포하는 도구는 유료 패키지의 포함 제품 수와 별도로 안내합니다.

컴퓨터 두 대에서 쓸 수 있나요?

기본은 1인·1PC입니다. 매장과 집처럼 두 곳에서 쓰셔야 하면 카카오톡으로 말씀해 주세요. 추가 라이선스로 안내드립니다.

윈도우가 아니어도 되나요?

윈도우 PC에서만 작동합니다. 맥에서는 쓰실 수 없습니다. 지금 쓰시는 컴퓨터가 괜찮을지 모르겠으면 시작 전에 사양을 보내주세요. 확인해 드립니다.

전에 구매한 평생 이용권은 어떻게 되나요?

그대로 유지됩니다. 구매하실 때 포함되어 있던 제품은 계속 쓰십니다. 새 1·3·6·12개월 기간형 요금제는 앞으로 시작하시는 분들께만 적용됩니다.

체험이나 결제는 어떻게 진행하나요?

체험판은 ‘무료 7일 체험판 받기’ 버튼으로 바로 내려받을 수 있습니다. 결제는 원하는 제품과 기간을 선택한 뒤 ‘결제하기’를 누르면 진행됩니다. 어떤 제품이 맞을지 모르겠다면 카카오톡으로 현재 하는 일과 줄이고 싶은 업무를 적어주세요.

어떤 일을 가장 먼저 줄이고 싶으세요?

원하는 제품을 알고 있다면 제품명과 이용 기간을, 아직 모르겠다면 하시는 일과 줄이고 싶은 업무를 적어주세요. 필요한 구성과 결제 방법을 안내합니다.
